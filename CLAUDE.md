# Venezuela Entrelíneas

- Sitio Jekyll publicado con GitHub Pages (build nativo de Pages, sin Actions). El dominio venezuelaentrelineas.com está en Namecheap y apunta aquí vía el archivo `CNAME`.
- Todo el contenido va en español. Tono: positivo, cercano, con valores; "noticias buenas" de Venezuela.
- Noticias: `_posts/AAAA-MM-DD-slug.md` con front matter `layout: post`, `title`, `categoria`, `resumen`, `autor` y opcional `imagen`. Ver README.md.
- Imágenes en `assets/img/`, optimizadas (ancho máximo ~1600px, JPG/WebP).
- Solo plugins permitidos por GitHub Pages (jekyll-feed, jekyll-seo-tag, jekyll-sitemap ya activos).
- El repo es público: nunca subir datos personales (cédulas, teléfonos, direcciones), claves ni documentos internos de la fundación o de Gráficas Capriles.
